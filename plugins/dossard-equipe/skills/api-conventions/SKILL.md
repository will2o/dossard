# Conventions des routes de dossard

Appliquer chaque point de `checklist.md` au router concerné, puis :

1. Lancer `pytest` et `ruff check .`.
2. Terminer la réponse par une ligne exactement de cette forme :
   `Conventions api-conventions : <n>/<total> points vérifiés`
